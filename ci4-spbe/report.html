Laporan Progress Pengembangan (Status Update)

Sistem Monitoring IoT SPBE BBPOM Bandung
Tanggal: 30 August 2026

Dokumen ini merangkum sejauh mana pengembangan sistem monitoring SPBE BBPOM (berbasis CodeIgniter 4 dan perangkat keras ESP32) telah diselesaikan hingga saat ini.

1. Arsitektur & Infrastruktur Sistem Selesai 100%

  • Backend Framework: Diimplementasikan menggunakan CodeIgniter 4 (CI4). Struktur routing, keamanan (API Keys), dan arsitektur kontroler telah berjalan stabil.
  • Database: Menggunakan MySQL. Skema tabel utama (seperti iot_sensor_logs, pegawai, spbe_evaluasi) sudah terdefinisi dan menyimpan data dengan format yang tepat.
  • Frontend: Berbasis antarmuka Single Page Application (SPA) dengan vanilla JavaScript, yang memastikan peralihan menu (Monitoring, Infrastruktur, Evaluasi) terjadi instan tanpa *reload* halaman.

2. Integrasi Perangkat Keras (IoT) Selesai 100%

Pengembangan dari sisi perangkat fisik (ESP32) telah selesai dikonfigurasi dengan fitur berikut:

  • Pembacaan Sensor: Sensor DHT22/11 (untuk Suhu & Kelembapan) dan Sensor MQ-135 (untuk Gas / Kualitas Udara) telah berhasil digabungkan dan dapat membaca metrik ruangan secara akurat.
  • Sistem Transmisi Cerdas: Skrip C++ pada Arduino sudah dilengkapi dengan fitur pengiriman payload JSON melalui HTTP POST (ke Endpoint CI4) dengan sistem perlindungan putus koneksi (Auto-Reconnect WiFi).
  • Alarm Otomatis (Buzzer): Logika proteksi telah diimplementasikan, di mana Buzzer akan berbunyi selama 10 detik apabila suhu lingkungan melebihi batas ( > 25°C ).

3. Modul Dashboard Monitoring Selesai 95%

Dashboard utama (di /monitoring) berfungsi secara penuh untuk menampilkan visualisasi data secara real-time:

  • Live Chart (Grafik Visual): Tren Pergerakan Suhu, Kelembapan, dan kualitas udara divisualisasikan dalam grafik garis interaktif yang terus diperbarui (auto-fetch setiap 10 detik) tanpa perlu menyegarkan halaman browser.
  • Smart Alert Banner: Fitur notifikasi di tampilan web yang secara dinamis berubah warna merah/hijau (Bahaya/Aman) berdasarkan data titik sensor suhu paling aktual.
  • Daily Recap Engine: Tabel ringkasan yang secara cerdas menotal nilai Rata-rata, Minimum, dan Maksimum dari seluruh pengujian sensor pada hari ini.
  • Export PDF & CSV: Sistem pendukung untuk langsung mencetak rekapan data sensor hari ini menjadi dokumen cetak atau format *spreadsheet* (Excel).
  • (Simulasi) Gauge Kelistrikan: Untuk purwarupa Alat 1 (Otomasi AC Ruang Keuangan), gauge voltase, ampere, dan watt saat ini masih menggunakan mesin simulasi, namun kerangka antarmukanya sudah 100% siap untuk disuntikkan data sensor sungguhan di masa depan.

4. Modul Admin & Pengaturan Dalam Proses (Tersedia Kerangka)

  • Halaman Admin Panel (/admin): Tata letak dan User Interface (UI) pengaturan batas Suhu & Kelembapan, serta status AC sudah dibuat.
  • To-Do Selanjutnya: Menyambungkan tombol 'Simpan' pada panel pengaturan tersebut langsung ke database melalui operasi CRUD, serta mengaktifkan layar Login/Authentication CI4.

Ringkasan Kesiapan Presentasi

Sistem ini sudah dapat didemonstrasikan sepenuhnya secara end-to-end. Anda dapat menunjukkan bagaimana perubahan suhu di sensor fisik (ESP32) langsung memengaruhi pergerakan grafik di *Dashboard* Web (berkat mekanisme Real-time Polling) serta memicu suara alarm apabila batas kritis dilewati.
